Questions & answers

Frequently asked questions.

What is YapperBrasilBot?

YapperBrasilBot is a Discord bot project created for Comunidade Brasil, with a focus on moderation, security and community features.

Is the source code available?

Visit the GitHub repository to explore the available source code, project files and updates.

Does this website show live bot statistics?

No. The cards and activity previews on this website are illustrative. Live statistics require a backend or an API connected to the running bot.

How can I contribute?

Check out the GitHub repository to review the project and explore ways to contribute.

Does the bot guarantee complete server security?

No. Moderation bots can help reduce abuse, but permissions, configuration, Discord settings and human moderation remain important.
