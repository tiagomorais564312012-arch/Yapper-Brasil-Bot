Perguntas frequentes

Dúvidas frequentes.

O que é o YapperBrasilBot?

É um projeto de bot voltado para a Comunidade Brasil, com foco em moderação, segurança e funcionalidades para os membros.

Como encontro um comando?

Vá até a seção Comandos, digite o nome ou uma palavra relacionada e utilize o filtro de categoria para refinar os resultados.

O website executa os comandos?

Não. A lista serve para consulta. Para executar um comando, é necessário utilizar a plataforma onde o bot funciona.

Posso entrar com minha conta Yapper?

Somente quando o login oficial estiver integrado. Não digite sua senha em formulários criados apenas para imitar uma tela de login.

Como adiciono o bot ao meu servidor?

O botão de instalação precisa apontar para o endereço oficial disponibilizado pelo Yapper para esse bot. A publicação pode depender de aprovação da plataforma.

As informações são atualizadas automaticamente?

Não nesta versão estática. A lista de comandos e outras informações são mantidas no próprio arquivo. Atualizações automáticas exigem uma integração com o bot ou com uma API.

O website funciona no celular?

Sim. O layout se adapta a telas menores, e o menu de navegação pode ser aberto pelo botão no topo da página.
